# 常见问题

## 启动失败，提示 `Address in use`

53 或 9099 端口被占用。常见的是系统自带的 `systemd-resolved` 占用了 53：

```bash
ss -lunp | grep ':53 '
```

关闭占用的服务，或在配置里修改 `listen` 端口。

## 某个域名分流不对

1. 打开「日志」，搜索这个域名，看它命中了哪条规则、用了哪个上游。
2. 需要更详细的过程，用「日志 › 诊断抓取」记录一次查询。
3. 如果是学习结果不对，在「域名学习」里清空该类别，或把域名加入白名单 / 灰名单。

## 改了规则没生效

规则保存后对**下一次查询**生效，但已缓存的应答会继续返回到过期为止。在「缓存设置」里清空缓存即可立即生效。

## 代理域名解析失败

FakeIP 模式下检查「上游设置 › 国外 FakeIP 上游」是否指向代理软件的 DNS 端口，并确认代理软件正在运行。见 [运行模式](/guide/modes)。

## 内存占用

主要取决于缓存条数和规则数量。默认配置在家用环境下通常在几十 MB。可以在「缓存设置」调小缓存容量。

## 配置检查报 `unsupported field`

AtomDNS 不会静默忽略不认识的参数。按提示删除该参数，或查看对应插件页确认支持的写法。

## 怎样完全恢复默认

- 只恢复设置：删除 `webinfo/settings.json` 后重启。
- 全部恢复：备份后清空配置目录，重新解压 `config_rust.zip`。

## 在哪里反馈问题

在 [GitHub Issues](https://github.com/jasonxtt/atomdns/issues) 提交，附上版本号（「系统管理」可见）和相关日志。

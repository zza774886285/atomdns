# 路由学习

名单外的域名第一次查询时要「试探」才知道该直连还是代理。路由学习把试探的结论记下来，之后同一域名直接按结论分流，又快又稳定。

## 记住什么

| 类别 | 何时记住 | 保留 |
| --- | --- | --- |
| 记忆直连 | 应答含中国 IP 或直连 IP | 7 天 |
| 记忆代理 | 应答只有非中国 IP | 7 天 |
| 记忆无 V4 | 域名没有 IPv4 地址（刷新时确认） | 8 天 |
| 记忆无 V6 | 域名没有 IPv6 地址 | 1 天 |
| 特殊域名 | 国内 DNS 无解析、国外 DNS 有解析 | 8 天 |

每条结论单独计时，从最后一次确认起算；过期后自动删除，下次查询重新试探。
定时 [刷新](/plugins/requery) 会重新确认常用域名，所以常用域名的结论会一直保持。

## 查看与管理

「规则设置 › 域名学习」页可以：

- 按类别查看记住的域名、命中次数、最后确认时间和原因；
- 搜索某个域名；
- 清空某个类别；
- 在「学习项目」里关闭某个类别（关闭即清空，且不再学习）。

## 优先级

学习结果的优先级低于手动名单和在线订阅：域名一旦被加入白名单、灰名单或订阅规则，就按名单走，学习结果不起作用。名单内的域名也不会被记入「记忆直连」「记忆代理」。

## 存储

学习结果保存在 `gen/route_learner.json`，每 6 小时和程序退出时写入。配置写法见 [route_learner](/plugins/route_learner)。

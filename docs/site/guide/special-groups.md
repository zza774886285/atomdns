# 专属分流组

专属分流组把一批指定的域名交给专门的上游和独立缓存处理，优先级高于普通分流。

典型用途：

- 流媒体域名交给能解锁的 DNS。
- 公司内网域名交给公司的 DNS。
- 某个游戏的域名交给延迟最低的 DNS。

## 组成

每个组包含：

| 部分 | 说明 |
| --- | --- |
| 名称 | 显示用 |
| 规则 | 在线订阅或手动填写的域名，决定哪些域名进入本组 |
| 上游 | 可引用已有上游组，或组内的单个上游，也可以添加只属于本组的上游 |
| 缓存 | 每组一个独立缓存，受「分组缓存」开关控制 |
| 自定义端口 | 可选，每组可以开一个只走本组的 DNS 端口 |

## 使用

在「规则设置 › 专属分流组」新建组，填写规则和上游，保存后立即生效。

- 引用的上游被停用或删除时，引用会显示告警并停止生效；该组没有可用上游时，组内规则也不再生效。
- 开启「仅自定义端口」后，本组只对发到自定义端口的查询生效；关闭时 53 端口和自定义端口都生效。

## 位置

在 [分流流程](/guide/flow) 中，专属分流组在屏蔽之后、DDNS 与普通分流之前执行。
多个组按序号顺序比对，先命中的组生效。

## 存储

组的定义保存在 `webinfo/special_upstream_groups.json`，程序据此生成 `sub_config/special_groups.yaml`。
不要手动修改生成的 YAML，它会被覆盖。

# 分流流程

本页说明全新安装包 `config_rust.zip` 里的默认配置怎样处理一条查询。只讲流程和概念，具体写法见各插件页。

## 总体顺序

一条查询从 53 端口进来，按下面的顺序处理，前面的步骤命中就不再往后走：

1. **重定向**：命中重定向名单的域名直接返回指定结果。
2. **类型屏蔽**：按开关屏蔽 SOA / PTR / HTTPS 或 AAAA 查询。
3. **规则匹配**：用一次查找把域名和所有名单比对，打上标记（白名单、灰名单、黑名单、DDNS、中国域名、非中国域名、学习结果等）。
4. **屏蔽**：黑名单、广告规则、已知没有 IPv4 / IPv6 地址的域名，按开关直接返回。
5. **专属分流组**：命中某个专属组的域名，交给该组自己的上游和缓存。
6. **DDNS 域名**：不使用过期缓存，保证拿到最新地址。
7. **全局缓存**：命中就直接返回。
8. **按名单分流**：按标记决定走国内还是国外上游。
9. **名单外域名**：先查一次，看应答 IP 是否属于中国，再决定直连还是代理，并把结论记下来。

## 名单内域名

规则匹配阶段打上的标记决定去向，优先级从高到低：

| 标记 | 去向 |
| --- | --- |
| 灰名单 | 国外（代理） |
| 白名单 | 国内（直连） |
| 自定义订阅·代理域名 | 国外 |
| 自定义订阅·直连域名 | 国内 |
| 非中国域名（geosite） | 国外 |
| 中国域名（geosite） | 国内 |
| 记忆代理 | 国外 |
| 记忆直连 | 国内 |

手动维护的白名单、灰名单优先级最高；自定义订阅优先于基础规则。

## 名单外域名

不在任何名单里的域名，按 [运行模式](/guide/modes) 先查一次：

- **兼容模式**：先问国内 DNS。速度快，但这次查询会被国内 DNS 看到。
- **安全模式**：只带 ECS 问国外 DNS，失败或没有结果也不回退国内。名单外的域名不会被国内 DNS 看到。

然后看应答里的 IP：

- 含有直连 IP 或中国 IP：按国内处理，记为「记忆直连」。
- 只有非中国 IP：按国外处理，记为「记忆代理」。

记下的结论在下一次查询时直接生效，见 [路由学习](/guide/route-learning)。

## 其它查询类型

A（IPv4）、AAAA（IPv6）和其它类型（MX、TXT 等）的查询按同样的名单优先级分流。

## 刷新（requery）

后台定时把最近查询过的域名在进程内重新查一遍：清空缓存后预热，同时确认或更新学习结果。
可在「缓存设置」页调整周期，见 [requery](/plugins/requery)。

# 功能开关

默认配置定义了 13 个功能开关，显示在「规则设置」各页的顶部。切换后立即生效。

| 开关 | 页面 | 默认 | 说明 |
| --- | --- | --- | --- |
| 核心运行模式 | 运行模式 | 兼容 | 兼容 / 安全，见 [运行模式](/guide/modes) |
| DNS 分流模式 | 运行模式 | FakeIP | FakeIP / RealIP |
| 国内域名 FakeIP | 运行模式 | 关 | 国内域名也返回 FakeIP |
| IPv4 优先 | 运行模式 | 关 | 有 A 记录时不返回 AAAA |
| DDNS 优先国外解析 | 运行模式 | 关 | DDNS 名单优先用国外上游 |
| 空结果屏蔽 | 请求屏蔽 | 开 | 已知无 IPv4 / IPv6 的域名直接返回空 |
| 黑名单屏蔽 | 请求屏蔽 | 开 | 屏蔽黑名单域名 |
| 类型屏蔽 | 请求屏蔽 | 开 | 屏蔽 SOA、PTR、HTTPS 查询 |
| 广告屏蔽 | 请求屏蔽 | 开 | 启用 AdGuard 在线规则 |
| IPv6 屏蔽 | 请求屏蔽 | 关 | 所有 AAAA 查询返回空 |
| 全局缓存 | 缓存设置 | 开 | 直面客户端的第一层缓存 |
| 分组缓存 | 缓存设置 | 开 | 国内、国外、专属分流组等各自的缓存 |
| 客户端分流 | 客户端 | 不区分 | 不区分 / 仅名单内客户端走代理 / 名单内客户端不走代理 |

## 值存在哪里

只保存与默认值不同的开关，位于 `webinfo/settings.json` 的 `flags` 段：

```json
{"version": 1, "flags": {"core_mode": "safe", "block_aaaa": true}}
```

## 自己添加开关

开关是配置里的 [`feature_flag`](/plugins/feature_flag) 插件，在 `sequence` 里用 `flag 名字` 引用。
新增的开关会自动出现在它所属的页面上。

# WebUI 导览

WebUI 在 `http://<主机 IP>:9099/`。日常调整都在这里完成，保存后立即生效，不需要重启。

![概览](/screenshots/overview.jpg)

## 页面一览

| 页面 | 用途 |
| --- | --- |
| **概览** | 查询量、平均响应、缓存命中、内存等实时指标；上游延迟与采纳率；分流占比 |
| **日志** | 每条查询的域名、应答、类型、耗时、客户端；可搜索、按客户端别名过滤；「诊断抓取」记录单次查询的完整处理过程 |
| **规则设置 › 运行模式** | 兼容 / 安全模式、FakeIP / RealIP、IPv4 优先等，见 [运行模式](/guide/modes) |
| **规则设置 › 上游设置** | 各上游组的上游列表、启用开关、延迟，以及 SOCKS5 代理与 ECS 地址 |
| **规则设置 › 分流规则** | 在线订阅、白 / 灰名单、FakeIP 过滤、直连 IP 与重定向、DDNS 域名 |
| **规则设置 › 请求屏蔽** | 黑名单、广告规则（AdGuard 订阅）、类型屏蔽 |
| **规则设置 › 域名学习** | 查看与清空 [路由学习](/guide/route-learning) 记住的域名 |
| **规则设置 › 缓存设置** | 各缓存的容量、过期保留时长、落盘间隔；查看与清空缓存；定时刷新（requery） |
| **规则设置 › 客户端** | 客户端别名、按客户端分流名单 |
| **规则设置 › 专属分流组** | 新建和编辑 [专属分流组](/guide/special-groups) |
| **系统管理** | 版本与在线更新、配置与界面更新、配置备份、审计日志容量、重启服务、界面主题 |

每个设置页顶部的开关就是 [功能开关](/guide/flags)，按所属页面自动归类。

## 小技巧

- 顶栏搜索框（<kbd>⌘</kbd> <kbd>K</kbd> / <kbd>Ctrl</kbd> <kbd>K</kbd>）可以直接跳到页面、设置项、域名或客户端。
- 日志搜索词加双引号表示精确匹配，例如 `"www.example.com"`。
- 右上角切换浅色 / 深色主题；手机上同样可用。
- 设置项标着「已修改」表示与默认配置不同，点「恢复默认」即回到配置文件里的值。

## 改动存在哪里

WebUI 的改动保存在配置目录的 `webinfo/` 下（主要是 `webinfo/settings.json`，只记录与默认不同的值），
配置文件本身保持不变。删除 `webinfo/settings.json` 即回到默认设置。

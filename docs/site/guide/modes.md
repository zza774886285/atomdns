# 运行模式

「规则设置 › 运行模式」页决定 AtomDNS 的整体工作方式。这些选项都是 [功能开关](/guide/flags)。

## 核心运行模式

决定名单外域名怎样首次查询。

| 模式 | 做法 | 适合 |
| --- | --- | --- |
| **兼容模式**（默认） | 先问国内 DNS，再按应答 IP 分流 | 追求速度 |
| **安全模式** | 只带 ECS 问国外 DNS，失败或没有结果也不回退国内 | 在意 DNS 泄露与劫持 |

两种模式使用各自的全局缓存，切换后会自动刷新一次缓存。

## DNS 分流模式

决定代理域名返回什么地址。

| 模式 | 代理域名返回 | 适合 |
| --- | --- | --- |
| **FakeIP 分流**（默认） | 代理软件分配的 FakeIP | mihomo、sing-box 等以 FakeIP 模式运行的透明代理 |
| **RealIP 分流** | 国外 DNS 解析的真实 IP | Redir-Host 方式，或不使用 FakeIP 的代理 |

::: warning FakeIP 模式需要设置上游
在「上游设置 › 国外 FakeIP 上游」填入代理软件的 DNS 地址，例如 `udp://192.0.2.1:6666`。
否则代理域名无法解析。
:::

## 其它选项

| 选项 | 说明 |
| --- | --- |
| 国内域名 FakeIP | 国内域名也返回 FakeIP（关闭时返回真实 IP） |
| IPv4 优先 | 域名有 A 记录时不返回 AAAA；纯 IPv6 域名照常解析 |
| DDNS 优先国外解析 | DDNS 名单内的域名优先用国外上游；兼容模式下国外失败回退国内，安全模式下只用国外 |

切换核心运行模式、DNS 分流模式或国内域名 FakeIP 后，程序会自动清空相关缓存并重新预热。
